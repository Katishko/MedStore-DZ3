# MedStore — учебный каталог лекарств

React Native / Expo-приложение, созданное на основе учебного проекта магазина канцтоваров. Каталог использует моковые данные лекарств из `mocks/db.json`.

## Возможности

- каталог лекарств и поиск по названию, латинскому названию, действующему веществу, производителю и форме выпуска;
- фильтрация по категориям;
- подробная карточка лекарства;
- корзина на Zustand с изменением количества и ограничением по остатку на складе;
- демонстрационное оформление заказа без отправки реального заказа.

## Запуск

Требуется установленный Node.js и npm.

```bash
npm install
npx expo start
```

Для запуска в веб-браузере:

```bash
npx expo start --web
```

## Данные

Моковые данные находятся в `mocks/db.json`. Структура соответствует объекту `drugs`, где каждая запись содержит название, латинское название, действующее вещество, категорию, форму выпуска, дозировку, производителя, флаг рецептурного отпуска, описание и остаток.

Цены и изображения в исходных данных отсутствуют, поэтому приложение их не отображает и не генерирует.

## Авторизация (ДЗ-4)

- Тестовый логин: `student`, пароль: `123456`.
- На экране входа пароль скрыт по умолчанию; кнопка рядом с полем переключает видимость.
- Защита от захвата экрана включена только на экране авторизации с помощью `expo-screen-capture`. Возможности ОС различаются: iOS не позволяет приложению полностью запретить обычный системный скриншот.
- GitHub использует OAuth Device Flow. Чтобы включить его:
  1. Создайте OAuth App в GitHub Developer Settings и включите **Enable Device Flow**.
  2. Скопируйте Client ID в `config/auth.ts`, заменив `YOUR_GITHUB_OAUTH_CLIENT_ID`.
  3. Client Secret в мобильное приложение не добавляйте. При входе откройте ссылку GitHub, показанную в приложении, и подтвердите выданный код.

Авторизация здесь учебная: тестовые учётные данные заданы в клиентском приложении, а токен GitHub не сохраняется между запусками.

## Отправка ДЗ-4 отдельной веткой и Pull Request

Из корня Git-репозитория создайте ветку от актуальной основной ветки:

```bash
git switch main
git pull origin main
git switch -c dz-4-auth
```

Установите зависимости и запустите приложение из каталога проекта:

```bash
cd rn-stationery-shop-master
npm install
npx expo start
```

После проверки авторизации закоммитьте изменения и отправьте ветку:

```bash
git add .
git commit -m "feat: add authentication screen"
git push -u origin dz-4-auth
```

На GitHub создайте Pull Request с `dz-4-auth` в основную ветку `main`, затем скопируйте URL PR в таблицу преподавателя.
