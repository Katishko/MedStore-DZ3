# MedStore — учебный каталог лекарств

React Native / Expo-приложение, созданное на основе учебного проекта магазина канцтоваров. Каталог использует моковые данные лекарств из `mocks/db.json`.

## Возможности

- каталог лекарств и поиск по названию, латинскому названию, действующему веществу, производителю и форме выпуска;
- фильтрация по категориям;
- подробная карточка лекарства;
- корзина на Zustand с изменением количества и ограничением по остатку на складе;
- демонстрационное оформление заказа без отправки реального заказа.

## Запуск

Требуется установленный Node.js и npm.

```bash
npm install
npx expo start
```

Для запуска в веб-браузере:

```bash
npx expo start --web
```

## Данные

Моковые данные находятся в `mocks/db.json`. Структура соответствует объекту `drugs`, где каждая запись содержит название, латинское название, действующее вещество, категорию, форму выпуска, дозировку, производителя, флаг рецептурного отпуска, описание и остаток.

Цены и изображения в исходных данных отсутствуют, поэтому приложение их не отображает и не генерирует.

> Учебный проект. Не предназначен для покупки лекарств и не заменяет медицинскую консультацию.
